# Kian-OS v2 (x86_64)

سیستم‌عامل Kian-OS v2 — معماری لایت‌ویت بر پایه Debian 12 (Bookworm)
- ۳ تم سوییچ‌شونده در ۰.۳ ثانیه (macOS / Windows 11 / Linux Native)
- شتاب‌دهنده گرافیکی ۶۰fps Wayland
- درایور کامل حسگر اثر انگشت (libfprint)
- لایه اجرای مستقیم نرم‌افزارهای ویندوز (Proton / Wine)
- نصاب گرافیکی دسکتاپ Calamares
